# Các Module Hay Dùng Với ESP32

ESP32 là một vi điều khiển mạnh mẽ với Wi-Fi và Bluetooth tích hợp, rất phù hợp để kết nối với nhiều loại module mở rộng khác nhau. Dưới đây là danh sách các module phổ biến và thú vị theo từng nhóm chủ đề.

---

## 🔌 KẾT NỐI – GIAO TIẾP

| Module         | Chức năng                | Ghi chú                          |
|----------------|--------------------------|----------------------------------|
| NRF24L01       | Truyền RF tầm xa         | Tốc độ cao, ổn định              |
| LoRa SX1278    | Truyền xa (5–10km)       | Dùng cho IoT vùng xa             |
| RS485 TTL      | Giao tiếp công nghiệp    | Bền, chống nhiễu tốt             |
| CAN Bus        | Giao tiếp trong ô tô     | ESP32 hỗ trợ CAN natively        |
| USB to TTL     | Nạp code/giao tiếp PC    | Dùng để debug UART               |

---

## 🌡️ CẢM BIẾN

| Module         | Mô tả                             | Ghi chú                     |
|----------------|-----------------------------------|-----------------------------|
| DHT22 / DHT11  | Nhiệt độ, độ ẩm                   | DHT22 chính xác hơn         |
| BME280 / BMP280| Nhiệt độ, áp suất, độ ẩm          | Giao tiếp I2C/SPI           |
| MQ-x           | Cảm biến khí (CO, khói, gas...)   | Có nhiều loại như MQ-2, MQ-7|
| AHT20 / AHT21  | Cảm biến nhiệt độ & độ ẩm hiện đại| Chính xác, giao tiếp I2C    |
| BH1750 / TSL2561| Cảm biến ánh sáng môi trường     | I2C                          |
| PIR HC-SR501   | Cảm biến chuyển động              | Dùng cho báo trộm           |
| HX711 + Load Cell| Cân điện tử                    | Đo khối lượng chính xác      |

## ✅ Gợi Ý Kết Hợp Module

| Mục tiêu                            | Gợi ý kết hợp module                                            |

| Báo trộm có hình, có tiếng          | `ESP32-CAM + PIR + Loa`                                         |
